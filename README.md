## How I work with AI

I integrate **Spec-Driven Development (SDD)** and **AI agents** into my engineering workflow, with specifications, project context, and validation guiding the work.

1. **Specify:** define the problem, requirements, constraints, and acceptance criteria.
2. **Provide context:** document architecture, conventions, integrations, and project decisions.
3. **Coordinate agents:** divide work into defined tasks for analysis, implementation, testing, and documentation.
4. **Review and validate:** inspect code changes, run tests, and check behavior against acceptance criteria and architectural decisions.
5. **Deliver and maintain:** integrate changes, deploy, and follow their behavior in production.

I remain responsible for technical decisions, code quality, security, and the final deliverable.
